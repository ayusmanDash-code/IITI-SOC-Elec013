## Quick Navigation & Summary

* **Project Overview**: Design and implementation of a High-Speed Dual Data Rate (DDR) Display Controller on an Artix-7 FPGA using Xilinx ODDR primitives and AXI4-Lite control.
* **Repository Structure**:
  * `Code/`: Verilog HDL design files, `.xdc` constraints, custom AXI IP, and testbenches.
  * `VideoOutput/`: Simulation and hardware-generated video output files and recordings.
  * `Waveforms/`: Simulation snapshot waveforms for DDR, AXI, and synchronization logic.
* **Key Features**: Hardware-level DDR data interleaving, AXI4-Lite dynamic register control via MicroBlaze, and Vitis-based keyboard interfacing.
* **Target Hardware**: Basys-3 Development Board (Artix-7 FPGA `xc7a35tcpg236-1`) with a VGA display interface.
* **Software Tools**: Xilinx Vivado v2023.2 and Xilinx Vitis.
* **Team (Elec-13)**: Harshit Gautam, Ayusman Dash, Anshu Yadav, and Yuvraj Diwakar, mentored by Rucha Gadgil.
