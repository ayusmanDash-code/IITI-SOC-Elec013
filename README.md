## Quick Navigation & Summary

* **Project Overview**: Design and implementation of a High-Speed Dual Data Rate (DDR) Display Controller on an Artix-7 FPGA using Xilinx ODDR primitives and AXI4-Lite control[span_0](start_span)[span_0](end_span).
* **Repository Structure**:
  * `Code/`: Verilog HDL design files, `.xdc` constraints, custom AXI IP, and testbenches[span_1](start_span)[span_1](end_span).
  * `VideoOutput/`: Simulation and hardware-generated video output files and recordings[span_2](start_span)[span_2](end_span).
  * `Waveforms/`: Simulation snapshot waveforms for DDR, AXI, and synchronization logic[span_3](start_span)[span_3](end_span).
* **Key Features**: Hardware-level DDR data interleaving, AXI4-Lite dynamic register control via MicroBlaze, and Vitis-based keyboard interfacing[span_4](start_span)[span_4](end_span).
* **Target Hardware**: Basys-3 Development Board (Artix-7 FPGA `xc7a35tcpg236-1`) with a VGA display interface[span_5](start_span)[span_5](end_span).
* **Software Tools**: Xilinx Vivado v2023.2 and Xilinx Vitis[span_6](start_span)[span_6](end_span).
* **Team (Elec-13)**: Harshit Gautam, Ayusman Dash, Anshu Yadav, and Yuvraj Diwakar, mentored by Rucha Gadgil[span_7](start_span)[span_7](end_span).
